# Alpha Atlas · AI 投研估值与研报库

GitHub Pages 静态研究站点，目前覆盖 9 家公司、10 条 A/H 证券行情：紫金矿业 A/H、紫金黄金国际、中国黄金国际、中国宏桥、云铝股份、哈尔滨电气、阳光电源、中微公司、宁德时代。

在线地址（已启用 GitHub Pages）：https://moliq1.github.io/ai-investment-research/

## 功能
- 研究总览：逐证券展示日期、货币及收盘价来源。
- 历史三情景估值：保留原有悲观、基准、乐观的 **区间或单点**，均标注当时研究日期、模型周期和假设；无历史结果就留空。个人试算单独保存在本机，不覆盖历史记录。
- 目标价记录：支持机构、评级、目标价、日期及来源链接。初始机构记录为空，不伪造券商观点。
- 历史报告库：已整理 10 份历史聊天**检索摘要重建版**（非完整逐字原文）；保留中国黄金国际与云铝股份等公司的多日期估值记录。
- 富途 OpenD 导入脚本、Yahoo 非官方行情的收盘价更新脚本、GitHub Actions 每工作日刷新与自动部署。

**数据状态（2026-10-21）：** 已从估值库完全删除虚构的 DEMO 目标价，改为可追溯到历史聊天检索摘要的模型结果及不完整记录。2026-10-20 四条收盘价已抓取；新增六条证券尚未取得收盘价时为 null，待 GitHub Actions 刷新。历史模型不能冒充最新目标价，富途券商数据尚未导入。

## 本地运行
```bash
python3 -m http.server 8000
# 在浏览器中访问 http://localhost:8000
```
不要直接双击 index.html；浏览器会阻止 file:// 读取 JSON。

## 发布
仓库 Settings → Pages → Build and deployment → Source 已选择 **GitHub Actions**。代码变更由 .github/workflows/pages.yml 发布；收盘价则由 .github/workflows/quotes.yml 于北京时间工作日 18:30 和 21:30 尝试更新，并在同一个工作流中重新部署网站（GitHub Actions 定时可能延迟或跳过）。如行情更新失败，页面保留以前的收盘价及日期，不会伪装为最新实时值。

## 数据同步
浏览器里修改的模型和机构数据仅保存在 localStorage，右上角可以导出 JSON；它不会自动写入 GitHub。若要更新共享数据，需要提交 data/*.json 到仓库。

```bash
pip install -r requirements.txt
python scripts/update_prices.py

# 仅在你自己的电脑运行本地 OpenD，并按富途官方 SDK 安装说明配置：
# pip install futu-api
python scripts/import_futu.py --host 127.0.0.1 --port 11111
```

富途目标价实际可否返回与 OpenD 连接、账号权限、证券覆盖有关，代码是导入适配层，并不表示当前已获得完整数据。

## 数据目录
- data/stocks.json：逐证券最后一个收盘快照。
- data/scenarios.json：按证券保存最近能恢复的历史独立估值，范围上下限可为空。\n- data/valuation_history.json：跨日期、不同假设的历史模型，不能混同。\n- docs/HISTORICAL_REPORTS.md：本次报告迁移说明与明确的证据限制。
- data/brokers.json、data/consensus.json：真实机构数据待导入。
- reports/*.md：从历史聊天的可恢复摘要重建的 10 份研究笔记；需另行核对和补充原文。
- docs/DATA_SOURCES.md：数据定义与限制。

**安全与版权：** 请勿将账户持仓、交易流水、密钥、个人账户数据放入公开仓库。未获授权的付费券商 PDF 仅保存合法来源链接，不复制原文。非投资建议。

## 历史估值与机构目标价的区别
归档的独立模型是历史对话里用盈利、PE、FCFF 等假设推演出的价格区间，不是富途/国内外券商公开目标价，也不代表2026-10-21的最新估值。已知但无法恢复完整三情景的紫金矿业、紫金黄金国际，仅保留部分模型与条件情景。详情参阅 [历史报告迁移说明](docs/HISTORICAL_REPORTS.md)。


## Markdown 主数据源（估值情景档案）

主导航新增「估值情景档案」（默认首页）。其估值数据直接从 [`sources/AI投研_公司估值情景汇总.md`](sources/AI投研_公司估值情景汇总.md) 读取，展示多公司三情景总表、原始参考股价及日期、估值区间与差幅、金属价格/利润/PE参数、关键经营判断和验证节点。

**新增公司：** 直接编辑这份 Markdown：在第一个「估值总表」增加一行，再在「分公司假设」写入 `### N. 公司名称（证券代码）` 及 `| 假设项目 | 悲观情景 | 基准情景 | 乐观情景 |` 参数表。GitHub Pages 发布后自动展示新公司（无需复制估值数字到 `data/scenarios.json`）。原有 `data/scenarios.json` 仅用于「三情景估值」历史档案页面；不要当成 Markdown 总表的第二个来源。

页面显示的估值差幅以 Markdown 的**参考价格和基准日**计算，不随着行情刷新悄悄改基准。报价快照独立显示，不是实时数据。所有模型均为独立情景假设，不是正式券商目标价。原始文件通过 GitHub 版本记录追踪每次更新。
