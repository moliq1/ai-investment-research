# 中微公司（688012.SH）2026Q2/H1 季报复查与估值修订

> 收盘价格日期：2026-10-23，¥266.70；快照版本：2026Q2-v1；  
> 财报原文：[2026年半年度报告](https://money.finance.sina.com.cn/corp/view/vCB_AllBulletinDetail.php?id=12505778&stockid=688012)；  
> 模型性质：独立研究，不是券商一致预期或买卖指令。2026Q3尚未披露，预披露日为2026-10-31。

## 一、本季与累计业绩事实（官方披露）

### 1. H1与Q2实际

| 指标 | 2026Q1 | 2026Q2单季 | 2026H1累计 | H1同比 |
|---|---:|---:|---:|---:|
| 营业收入 | 29.15亿元 | **37.76亿元** | **66.91亿元** | **+34.89%** |
| 归母净利润 | 9.30亿元 | **18.95亿元** | **28.25亿元** | **+300.22%** |
| 扣非归母净利润 | 4.78亿元 | **6.45亿元** | **11.23亿元** | **+108.36%** |
| 经营活动现金流 | -1.59亿元 | **约8.43亿元** | **6.85亿元** | **+237.39%** |

Q2单季=H1累计-Q1；Q1来自2026年第一季度报告。归母利润受非经常收益显著影响，扣非和现金流更适合作为核心经营锚。

### 2. 利润质量与再投资

- [事实] H1毛利率约**39.74%**；研发投入**20.41亿元**，占收入**30.51%**。
- [事实] H1研发费用**13.10亿元**，资本化开发支出相关现金支付**6.80亿元**；期末开发支出**21.06亿元**，较2025年末+37.18%。
- [事实] H1购建固定资产、无形资产及其他长期资产现金支出**7.77亿元**。
- [模型计算] SOP简化FCF = CFO 6.85 - CapEx 7.77 ≈ **-0.92亿元**；若进一步扣除资本化研发现金，严格研究FCF约**-7.72亿元**。
- [事实] 应收账款**30.58亿元**，较年末+53.90%；存货**76.66亿元**，较年末+6.92%，其中发出商品约31.78亿元。
- [事实] 货币资金**97.68亿元**；短期借款1.39亿元、一年内到期长期借款约2.54亿元、长期借款4.82亿元，[模型计算]净现金约**88.9亿元**。
- [事实] 期末总股本**957,842,348股**；资本公积转增属于机械股数调整，估值直接使用当前总股本。

### 3. 经营与平台化进展

- [事实] H1先进逻辑和先进存储关键刻蚀设备新增付运显著增加，多种关键刻蚀工艺实现大规模量产。
- [事实/公司披露后外部整理] CVD、HAR及ALD钨系列产品通过关键存储/逻辑客户验证并取得重复量产订单；EPI、MOCVD、先进封装产品继续验证或重复订货。
- [事实] 2026年完成中微众硅控股并表，补齐CMP设备，H1新增商誉约**10.60亿元**。
- [事实] 2026-10-13公司拟追加不超过3500万元投资青禾晶元，本轮后合计持股约7.0718%，用于先进封装键合相关战略布局；该投资规模不足以单独改变本期估值。
- [重大警示] 平台化产品多数仍需要以可识别收入、毛利和ROIIC验证，不能用“覆盖更多设备市场”直接替代现金流预测。

## 二、上版预测与本季实际对照

### 1. 冻结旧版

本次更新前，主MD中的中微公司模型为2026-09-04历史聊天研究：
- 参考价：**¥335.42**；
- 悲观/基准/乐观：**¥46–73 / ¥115–209 / ¥197–356**；
- 反向DCF：在WACC10%、永续增长4%、成熟EBIT率28%等假设下，旧价约需要未来5年收入CAGR 48%，或30%增长持续8–9年。

**重要限制**：旧版研究发生在2026H1财报已经披露之后，所以本次没有“新季报实际 vs 旧季度预测”的真正预测误差；旧Git档案也没有保存逐项2026E营收、扣非和FCF预测，因此这些旧值标记为**无法恢复**，不事后补造。

### 2. 本次修订的真实原因

| 项目 | 旧版 | 本次核验/更新 | 变化原因 |
|---|---:|---:|---|
| 参考股价 | ¥335.42（9-4） | **¥266.70（10-23）** | 市场价格下降约20.5%，与模型事实分开记录 |
| H1核心经营 | 已在聊天中使用，但Git摘要未正式核验 | **营收66.91、扣非11.23、CFO6.85亿元** | 正式按公告回溯并补齐口径 |
| 简化FCF | 未结构化留档 | **约-0.92亿元** | CFO-CapEx仍为负，限制估值上修 |
| 严格研究FCF | 未结构化留档 | **约-7.72亿元** | 进一步考虑资本化研发现金 |
| 应收/存货 | 未结构化留档 | **应收+53.9%、存货+6.9%** | 应收增长快于收入，是现金质量风险 |
| 股本 | 旧模型已注意转增 | **9.5784亿股** | 当前每股价值统一按最新股本 |
| 机构2027/28归母均值 | 旧版未正式归档 | **47.12/61.33亿元** | 2026-10-25的22家机构汇总，用于交叉验证 |
| 三情景估值 | 46–73 / 115–209 / 197–356 | **60–85 / 135–185 / 235–325** | H1核心盈利和新品证据增强，模型收敛；同时提高对FCF和资本效率纪律 |

结论不是“业绩不及预期导致下修”；相反，H1核心经营强于此前历史盈利水平。本次主要是把估值从宽泛长期区间改成可勾稽的10年FCFF模型，并把价格、现金流和再投资统一起来。

## 三、最新盈利与三情景估值

### 1. 外部一致预期，仅作校验

截至2026-10-25，同花顺汇总22家机构：
- 2026E / 2027E / 2028E归母净利润均值：**38.99 / 47.12 / 61.33亿元**；
- 2026E / 2027E / 2028E收入均值：**169.13 / 227.05 / 294.35亿元**；
- 按10-23市值约2554.6亿元，对应2027E/2028E PE约**54.2×/41.7×**。

归母盈利含投资收益波动，本项目不直接把这些净利当成FCFF。

### 2. 独立DCF

模型起点以2026E收入约169亿元为基准锚，税率15%，用“EBIT税后利润 - 再投资”得到FCFF。再投资由收入增长和销售/投入资本效率联动；权益桥仅加回约89亿元净现金。

| 假设 | 悲观 | 基准 | 乐观 |
|---|---:|---:|---:|
| 2027–2031收入增速 | 20%→12% | **30%→18%** | 35%→22% |
| 2026→2031收入CAGR | ~16% | **~24%** | ~28% |
| 2031收入 | ~355亿元 | **~494亿元** | ~588亿元 |
| 2031 EBIT率 | ~19% | **~24%** | ~28.5% |
| 成熟EBIT率 | ~22% | **~28%** | ~32% |
| 增量销售/投入资本 | 1.25→1.5× | **1.4→2.0×** | 1.5→2.2× |
| WACC | ~10.5% | **~10.0%** | ~9.5% |
| 永续增长 | 3.0% | **3.5%** | 4.0% |
| **每股价值** | **¥60–85** | **¥135–185** | **¥235–325** |
| 相对¥266.70 | -78%至-68% | **-49%至-31%** | -12%至+22% |

基准终值占企业经营价值约80%，说明长期假设仍然敏感。估值区间不是概率加权目标价。

### 3. 反向DCF

在WACC10%、永续增长3.5%、成熟EBIT率28%、终端销售/投入资本约2.0×、净现金约89亿元不变时：

- 当前¥266.70大致需要**约40%的2027–2031收入CAGR**；
- 或者在未来5年收入约30%增长的情况下，需要成熟EBIT率升至**约37%**。

这比旧价¥335.42隐含的约48%五年CAGR明显缓和，但仍高于本项目基准约24%的2026→2031收入CAGR。

### 4. PE交叉验证

- 按机构2027E/2028E归母均值，现价约54×/42×PE；
- 本项目更关注核心经营利润。基准情景2028核心税后经营利润约43亿元，若给予35–45×远期PE并折现回研究日，得到的价值与基准DCF大致相容；
- 2026-10-22华兴证券按2027E净利58.24亿元并给予约70×PE，目标价425元，属于更乐观的倍数框架，不是本项目基准。

## 四、风险、失效条件与下期核验

### 当前结论

- **成长门槛**：通过；
- **估值状态**：偏高；
- **估值赔率**：不足，但较9月4日明显改善；
- **预期差**：负向为主；
- **当前结论**：等待价格；
- **下一强制复核**：**2026-10-31 Q3正式报告**。

### 核心失效条件

1. 刻蚀和薄膜设备收入增速连续降至20%以下，且新增订单/反应台没有补偿；
2. 应收持续快于收入、CFO和FCF连续不能改善，说明高增长无法转化为现金；
3. 薄膜/CMP/量检测/先进封装长期停留验证或小批量，平台化资本开支无法形成可见ROIIC。

### Q3必须核验的五项

1. Q3单季收入、扣非净利润和毛利率；
2. CFO、CapEx、资本化研发现金与简化FCF；
3. 应收账款、存货和合同负债变化；
4. 先进逻辑/存储刻蚀新增付运和薄膜设备重复订单；
5. 众硅CMP并表收入/毛利、平台化新品可识别收入及新增资本开支。
