**营运资金**：期末应收账款34.014亿元（2025末29.108亿）、存货45.150亿（2025末27.747亿，+62.72%）、其他应收1.758亿（初值0.273亿，公司称保供保证金）、预付款1.821亿（初值0.849亿），对应保证金与物料提前采购成本。9M CFO-3.526亿较2025同期+0.907亿减少4.432亿元。管理层表示AI电源存货增量为主，既含已获得订单也含需求预测备货，因此**不能把全部库存计为确定订单**。

**AI业务证据纪律**：[管理层] 公司10-30明确表示不单独披露AI电源收入；GB300产能持续爬坡、订单充足；Vera Rubin首批订单正在争取；800V/SST可能持续渐进推广至未来一至两年，而非立即全部替换。2026H1电源事业群收入18.41亿、同比+60.92%、毛利率25.06%可以作为已实现业务锚，但不能外推成Q3独立AI电源收入/毛利。NVIDIA固件支持Megmeet PowerShelf为生态集成客观证据，不代表GB300或Rubin份额。

**权益桥（亿元，模型代理）**：
- 2026Q3末货币资金8.033 +交易性金融资产15.358+一年内到期非流动资产0.742≈24.134；其中并非全部无限制现金，流动性需复核。
- 短借6.485+一年内到期负债0.649+长借1.300+租赁负债0.696≈9.129。
- 收购深圳焊接少数权益相关负债：交易性金融负债1.799+其他非流动负债4.198+长期应付职工薪酬0.447≈6.444；**不能再另减拟收购少数股权6.64亿**。
- 期末少数股东权益账面约0.352；归母权益桥≈24.134−9.129−6.444−0.352=**8.21亿元**，模型保守采用+8.2亿。其他非流动金融资产13.878亿不作为可用现金额外加回。
- 期末股本**585,260,736股=5.85260736亿股**。参考市值¥77.72×5.85260736≈**454.86亿元**；合并经营EV代理≈**446.66亿元**。H股后续发行条款尚未明确，不做虚构增发模拟。

## 三、盈利路径、三情景DCF、反向估值与压力测试

**2026Q4所需收入（数学门槛）**：9M 90.36亿，2026FY悲观115–121、基准122–129、乐观128–134亿元，分别要求Q4收入24.64–30.64、31.64–38.64、37.64–43.64亿元。相对2025Q4约26.12亿，同比悲观约-6%至+17%、基准+21%至+48%、乐观+44%至+67%。这不是公司指导，亦不等同单季AI收入。

### DCF假设和结果（模型端点整组联动）

| 参数 | 悲观低 / 高 | 基准低 / 高 | 乐观低 / 高 |
|---|---|---|---|
| 2026收入（亿元） | 115 / 121 | 122 / 129 | 128 / 134 |
| 2026 EBIT率 | 2% / 3% | 2.5% / 3.5% | 3.5% / 4.0% |
| 2031稳态EBIT率 | 7.5% / 9% | 10% / 12.3% | 13% / 14% |
| 2027–31逐年收入增长 | 12/10/9/8/7% 或 19/17/15/12/10% | 22/20/17/14/11% 或 32/28/24/20/16% | 33/29/25/21/17% 或 40/35/30/25/20% |
| 2032–35逐年增长 | 6/5/4/3% 或 8/6/4/3% | 8.5/6.5/4.5/3.2% 或 12/9/6/4% | 13/9/6/4% 或 15/11/7/4.3% |
| Sales/Invested Capital | 1.7 / 2.0 | 2.0 / 2.5 | 2.4 / 2.7 |
| WACC | 11% / 10.2% | 10.1% / 9.2% | 9.1% / 8.7% |
| 永续g | 2% / 2.5% | 2.5% / 3% | 3% / 3.3% |
| **每股价值（¥）** | **11.1 / 22.0** | **27.8 / 71.5** | **80.0 / 134.0** |

**公式**：2026收入、EBIT率作为起点，2027—2031 EBIT率每年以相等百分点向2031目标过渡，2032–2035保持2031稳态。NOPAT=当年收入×EBIT率×(1−18%税率)；再投资=当年新增收入÷Sales/Invested Capital；FCFF=NOPAT−再投资；终值2036 FCFF=2035收入×(1+g)×稳态EBIT率×82%−2035收入×g/Sales/Invested Capital；企业价值为2027–2035年FCFF按当年WACC折现之和，加上2036年终值/(WACC−g)在2035年末的折现值。股权价值=企业价值+8.2亿元权益桥；除以5.85260736亿股。**该模型没有假设增长不需再投资；稳态ROIC≈EBIT率×82%×Sales/Capital。** 现金流在初期可能为负，已通过再投资扣减体现。

模型端点显示终值约占经营价值的**83%–85%**，因此估值依赖多年之后的利润率、增长、资本回报假设，不可作为确定目标价。本次不新增尚无法验证的AI电源独立收入/份额模型。

### 反向DCF（现价隐含要求）

固定2026收入125亿、2026EBIT率3%、Sales/Capital2.2×、WACC9.5%、税18%、永续g2.75%、权益桥8.2亿、股本5.85260736亿；2027–2031收入保持单一增长率，2032–2035增长率按此前五年增速×75%/55%/35%及最终3.5%收敛。反推¥77.72：

| 2031/稳态EBIT率 | 五年收入CAGR |
|---:|---:|
| 9% | **40.1%** |
| 11% | **31.9%** |
| 13% | **26.3%** |
| 15% | **22.0%** |

二维压力测试（元/股）：

| 稳态EBIT率 / 五年收入增速 | 20% | 25% | 30% | 35% |
|---|---:|---:|---:|---:|
| 9% | 34.8 | 42.2 | 51.5 | 63.2 |
| 11% | 46.8 | 57.8 | 71.7 | 88.9 |
| 13% | 58.9 | 73.5 | 91.8 | 114.6 |

**[模型推断]** 目前股价仍要求多年高增长与稳态利润率大幅改善，且要求资金投入效率不能过差。反向DCF的恒定增长路径是为了隔离两项敏感变量，不是将该值冒充为市场已披露共识。

### 现金流压力测试（基准中点）

基准模型中点约¥45.1，稳态EBIT率11.2%、Sales/Capital 2.25×。在其余假设不变时：长期EBIT率10%→约¥38.4；资本周转下降至1.8×→约¥40.1；2027增长放缓、后续不足以追回→约¥39–43。额外5%股份稀释在**尚未计入募资现金**的纯机械测试下中点降至约¥43，真实发行必须同时计入新现金及投资回报，不能只扣股份。

**券商PE校验**：[市场预期] 东吴证券2026-11-01单家最新预测2026/2027/2028归母6.4/12.9/18.8亿（此前8.0/16.1/25.6亿）。以市值454.9亿，对应约71/35/24倍PE。2028归母18.8亿÷5.8526亿股≈EPS3.21元，给予25–30×2028PE并按10%折现两年，约得**¥66–80**；这是含有盈利恢复假设的PE交叉验证，不是FCF估值的替代，也不是最新15家机构平均共识。

**赔率**：基准区间¥28–72相对¥77.72为**-64%至-7%**，没有正的基准上涨空间；悲观¥11–22约-86%至-72%，乐观¥80–134约+3%至+72%。基准上行/悲观下行比值为**0或不适用**。上涨只有在AI高增长持续、利润率接近较强国际同行且现金转换得到明显修复时才具备DCF支持。

## 四、预期差、证伪条件与未来复核

1. **利润率（负向，中置信度）**：Q3扣非转负、整体毛利率20%、研发及减值叠加。若2026Q4和2027Q1扣非持续正增长、毛利率连续回升且公司级利润率显著改善，则上调2026锚及2031EBIT率；否则下修盈利路径。
2. **营运资本与现金（负向，中置信度）**：存货45.15亿、保证金与预付款增加、9M CFO-3.53亿。关注2026FY CFO和库存周转，若全年简化FCF仍显著为负且库存增长快于收入，则下调Sales/Capital。
3. **Rubin/GB300份额（潜在正向，低置信度）**：官方生态支持与GB300持续交付为正面；Rubin首批订单尚未确认收入，800V商业化需要时间。2027H1若披露批量收入、持续复购或更多可核验客户，将有条件上调乐观概率；不能仅以管理层目标推导份额。
4. **资本配置**：深圳焊接剩余股权收购负债约6.44亿已经部分体现在报表，关注实际交割和业绩归属。H股融资股数、价格、募集净现金及新增资本回报必须同步纳入每股模型。
5. **硬性否决**：截至2026-11-02无法确认触发审计否定、持续经营危机或无实质AI业务的否决事项；但连续现金流弱于利润是警示，不能把“有解释”当作“资金占用不重要”。
